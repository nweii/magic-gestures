# Trickpad icon lab

This folder preserves the standalone palette and geometry playground used to develop the Trickpad app icon. It does not affect the application build.

From the project root, start it with:

```bash
python3 -m http.server 4177 --directory design/icon-lab
```

Then open `http://127.0.0.1:4177/`. The captured settings JSON records the baseline that preceded the final Icon Composer artwork.
